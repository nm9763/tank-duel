# 双人坦克大战 · Tank Duel

一个纯前端（零依赖、零安装）的双人坦克对战小游戏，单文件 HTML 即开即玩。
支持 **电脑双人同屏**、**手机双摇杆**，以及 **房间号联机对战**。

> 所有版本都是独立的单 HTML 文件，双击即玩，不需要 Node、不需要构建、不联网（联机版除外）。

## 玩法

### 电脑版键位

| 操作 | 玩家 1（蓝） | 玩家 2（红） |
| --- | --- | --- |
| 移动 | `W` `A` `S` `D` | `↑` `↓` `←` `→` |
| 开火 | `空格` | `Enter` |
| 布雷 | `Q` | `/` |
| 重开 / 选地图 / 音效 | `R` / `Backspace` / `M` | 同左（通用按键） |

- 单人模式下玩家 2 由 AI 接管。
- 支持选图、回合制、比分统计，先到 5 分获胜。
- 模式选择界面按 `1` / `2` 或 `←` `→` 选模式，`Enter` 进入选地图。

### 手机版

- 左右双摇杆，左侧移动、右侧瞄准/开火，布雷按钮独立。
- 自动强制横屏（整页旋转 90°，不依赖系统旋转锁）。
- 适配刘海屏/安全区，禁用手势缩放与长按菜单。

### 联机版

- 一台点「创建房间」拿到 6 位房间号，另一台输入房间号加入。
- 房主做权威模拟，成员不跑本地物理，画面由房主 25Hz 快照驱动，保证双方一致。
- 成员本机的方向按键被采集为方向布尔量上报，由房主映射为玩家 2 键位。

## 特性

- **四张地图**：经典对称、回廊纵横、环形要塞、四分战场，四张地图共用紧贴活动区外侧的边界墙。
- **道具系统（9 种）**：补血 `+`、快速射击 `»`、三连发 `≡`、加速 `^`、护盾 🛡、反弹弹 🔄、穿甲弹 💥、冻结 ❄、地雷包 💣。
  - 散射会削弱单发伤害（15），避免三连过于无解。
- **地雷**：贴身缠斗时可布雷逼走位，AI 也会躲雷。
- **AI 对手**（单人模式）：
  - 估计对手速度打提前量，按子弹飞行时间迭代两次预判命中点；
  - 缓慢游走的瞄准误差，避免「百发百中」（对手被冻结时误差归零，稳稳吃下输出）；
  - 威胁评估：躲避正在飞向自己的子弹，只侧闪不留后撤，边躲边压；
  - 道具按「收益 − 距离代价」打分，交火中只捡很划算的；
  - 前方被挡时「承诺」一个绕行方向并坚持一段，避免每帧换边导致左右摇摆；
  - 有射界且炮口对准才开火，有反弹弹时借墙打。
- **纯 Canvas 手写渲染 + WebAudio 音效**，无任何第三方库。

## 本地运行

直接双击 HTML 文件即可。若想用本地服务器（联机版/剪贴板 API 更稳）：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000

# 或 Node
npx serve .
```

## GitHub Pages

仓库根目录的 `index.html` 是版本导航页。在仓库 **Settings → Pages** 里选择
`main` 分支、`/ (root)` 目录，即可得到一个在线试玩地址。
